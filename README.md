# codingcuisine.dev — Platedraw

Give it a word, get a dish. Platedraw turns any word into a recipe and a
pen-line drawing of the plate. Same word, same dish, always.

To add content, extend `src/lib/pantry.ts`: a new ingredient, technique,
sauce or cuisine is picked up everywhere automatically.

Live at **https://codingcuisine.dev** (Firebase Hosting; also
https://codingcuisine.web.app).

Implemented from the Claude Design project *Coding Cuisine*
(`Coding Cuisine.dc.html` + `PlateCard.dc.html`).

## Screens

| Path | Screen |
| --- | --- |
| `/` | Welcome — Fourier epicycles write the wordmark, then morph into a plate |
| `/plate` (`?w=word`) | Plate — seed word → recipe, flavour radar, drawing, downloads, Share. Old `/?w=` links redirect here |
| `/forks` (`?w=word`) | Fork lineage of a dish |
| `/guide` | Field guide — twelve plates, filterable by cuisine |
| `/today`, `/day/YYYY-MM-DD` | Dish of the day — the date is the seed |
| `/card` (`?w=word`) | 6 × 4 in recipe index card: recipe on the front, postcard on the back with the plate as a stamp. Prints as two exact 6 × 4 in pages. Share button. `/postcard` redirects here |
| `/parts` | Component sheet |

Downloads from the Plate screen: static SVG, SMIL-animated SVG, HPGL plotter
file (`.plt`, 1 unit = 0.5 mm) and a `.forkrecipe` JSON recipe.

Share (Plate and Card): a 7 s MP4 of the plate being drawn, or a PNG, as an
Instagram post (4:5) or story (9:16). Touch devices get the system share
sheet; desktops download.

Dish pages (Plate, Card, Forks, Today) are tinted with their cuisine's colours.
The site is vegetarian: meat and fish words become a vegetarian swap with a quip.

## Code map

- `src/lib/pantry.ts` — the content: 143 vegetarian ingredients (form, colour, seasons, suitable techniques, aliases, optional `overrideKind` arrangement), 29 techniques, 11 cuisines (sauces, crunches, herbs, acids, heat) and 71 `SWAPS` for meat and fish words
- `src/lib/dish.ts` — the generator: the word picks an ingredient (one named in the word wins; `YYYY-MM-DD` seeds stay in season), a cuisine (cuisine words like "miso" or "tahini" steer it) and a technique; everything else is derived under pairing rules. Also fork lineage, the field guide and `PUN_WORDS` for Surprise me
- `src/lib/look.ts` — `PlateLook`, the contract between the generator and the drawing
- `src/lib/rng.ts` — seeded PRNG (djb2 → mulberry32); never use `Math.random` for anything that must be repeatable
- `src/lib/fourier.ts` — DFT, inverse, epicycle chain and coefficient blending for the welcome animation
- `src/lib/welcome-paths.ts`, `src/lib/wordmark.ts` — the welcome loops; `wordmark.ts` is generated by `scripts/bake-wordmark.mjs` from Hershey Script 1 (see that file for the Hershey Fonts acknowledgement)
- `src/lib/plate.ts` (+ `plate-*.ts`) — procedural plate drawing → on-page SVG, SVG/animated SVG files, HPGL
- `src/lib/download.ts` — download buttons and the ForkRecipe format
- `src/lib/seo.ts` — per-route head tags (title, description, canonical, Open Graph, Twitter) and Recipe JSON-LD; `App.tsx` calls `useSeo(routeSeo(...))` once. `index.html` holds the same site-wide defaults for scrapers that don't run JavaScript (a test keeps them in step)
- `src/lib/sitemap.ts` + `scripts/build-sitemap.mjs` — `npm run build` writes `dist/sitemap.xml` (static routes plus `/plate?w=` for every ingredient, field-guide and pun word); `public/robots.txt` points to it
- `public/og/default.png` — the 1200 × 630 share image, rendered once from `scripts/og-default.html` (see its header for how to re-render)
- `src/lib/palettes.ts`, `src/lib/cuisine-theme.ts` — per-cuisine palettes (WCAG AA checked by tests) and `useCuisineTheme`, which sets the CSS variables on dish pages
- `src/lib/share-frame.ts` — draws one share frame on any 2D canvas (no DOM); `src/lib/share-video.ts` — MP4 encoding (WebCodecs + Mediabunny), PNG still, share-or-download; `src/lib/device.ts` — light device checks
- `src/components/PlateCard.tsx` — the card; `draw` animates, `frozenAt` freezes mid-drawing, `bare` drops the paper
- `src/components/ShareButton.tsx`, `ShareSheet.tsx`, `lazy-share.tsx` — the share panel, loaded on demand with a chunk-load fallback; `Stamp.tsx` — the card's plate stamp; `Radar.tsx` — the flavour radar
- `src/lib/station.ts` — **the station** ("food, cooked by code"): a dish's drawing becomes Strudel code in five parts, one per drawn layer. Cuisine → key and instruments (`CUISINE_SOUND`); arrangement → melody (`MOTIF`); plate shape → room (`ROOM`); sauce style → bass (`SAUCE_GESTURE`); garnish → sparkle (`GARNISH_VOICE`); strokes → note density and length; colours → filter. Pure, no Strudel import. **Tune the music here.**
- `src/lib/instruments.ts` — every voice by name; add an instrument with one line. `src/lib/station-tracks.ts` (+ `-classic.ts` Chef's Table, `-eno.ts` Eno and Mix) — the ambient styles, written for the recorded instruments (paste a track into strudel.cc to tune it; the code sound swaps samples for synths). `src/lib/station-settings.ts` + `src/components/RadioMenu.tsx` — the Radio ▾ settings. `public/station/` — recorded instruments and kitchen loops, rebuilt with `scripts/station-samples.py`. `src/lib/station-welcome.ts` — the welcome circles as sine partials
- `src/lib/station-transition.ts` — fades and the build-up with the drawing (pure, clock-driven); `src/lib/station-state.tsx` — the App-level provider and `useStation()`; `src/lib/station-engine.ts` — the only module that imports Strudel, loaded on the first press of Radio; `src/components/RadioTab.tsx`, `StationCode.tsx` — the nav button and the code beside the recipe; `src/lib/station-render.ts` + `share-audio.ts` — the share video's soundtrack: the dish's music rendered offline for the 7 s clip (AAC; silent where the browser can't encode it); `src/lib/strudel-check.ts` — test helper that evaluates every pattern without audio
- `src/**/*.test.ts(x)` — vitest suite
- `src/screens/*` — one file per screen; `src/App.tsx` holds routing and the plated word

## Develop

```
npm install
npm run dev       # http://localhost:5173
npm test          # vitest run — CI runs this before the build
npm run build     # tsc -b && vite build → dist/
```

## Deploy

GitHub Actions (`.github/workflows/deploy.yml`) tests, builds and deploys on every
push to `main` (live) and every PR (7-day preview channel). It needs the repo
variable `FIREBASE_PROJECT_ID` and secret `FIREBASE_SERVICE_ACCOUNT`.
