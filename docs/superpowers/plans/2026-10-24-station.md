# Station Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "Food, cooked by code": an ambient Strudel "station" whose music comes from the plate drawing itself, that plays across the whole site, builds each dish's music as its plate draws, and shows the dish's Strudel code beside the recipe. The site goes public under AGPL first.

**Architecture:** A pure `station.ts` turns a `Dish` into a Strudel code string with five parts, one per plate layer, and holds the transition rules. A React provider at `App` level owns play/pause and the current target and survives route changes. Pages declare what they show with `useStation(...)`. The only module that imports Strudel is `station-engine.ts`, loaded on first press of Radio. It evaluates code strings and drives per-part and master gain through `ref()` accessors, which gives fades and build-ups without re-evaluating.

**Tech Stack:** React 18, TypeScript, Vite 5, vitest. `@strudel/web` 1.3.0 (AGPL-3.0-or-later), with `@strudel/core`/`@strudel/mini`/`@strudel/transpiler` 1.2.6 for tests.

**Spec:** `docs/superpowers/specs/2026-10-24-station-design.md`

## Global Constraints

- Strudel versions pinned exactly: `@strudel/web` `1.3.0`. Test-only `@strudel/core`, `@strudel/mini`, `@strudel/transpiler` `1.2.6`. No `^`.
- No Strudel module in the initial bundle. Only `src/lib/station-engine.ts` imports `@strudel/*` at runtime, and only through a dynamic `import()`.
- Never autoplay. `initStrudel`/audio resume runs inside the Radio click handler.
- Determinism: building patterns uses `rng()` from `src/lib/rng.ts`, never `Math.random` (the ambient shuffle is the only exception, per spec §4).
- **No user text in Strudel code.** Code strings contain only fixed tokens and numbers, the same rule as the plate SVG. Titles and words appear only as React text.
- Calm ranges: tempo `setcpm` between **15 and 20** (60–80 bpm at 4 beats per cycle). Part gain ≤ **0.35**, master gain default **0.5**.
- Plate layers in order **plate, sauce, main, crunch, herbs** at **0, 0.9, 1.6, 2.4, 3.0 s**, each **0.9 s** (`plate.ts`).
- Transitions: dish with a drawing → old music fades out in **1.2 s**, then the build-up. Every other change → **3 s out + 3 s in** (6 s total, inside the spec's 4–8 s).
- Synth voices only in v1 (`sine`, `triangle`, `sawtooth`, `square` + `lpf`/`room`/`delay`). No `samples()`, no soundfonts, no third-party fetches. *Claude's call* within the spec's "builder's call", so the station can't break if strudel.cc is down.
- `npm test` and `npm run build` pass before every commit. Branch, PR, preview, merge only on the owner's word.
- Code panel is hidden in print (`@media print`).

## Review Focus

1. **Seed words with quotes, backticks, newlines or `*/`** (e.g. `"); hush(); //`) must produce valid, identical-shape code, because user text never reaches the code. Test in Task 2.
2. **Fast navigation** (plate → guide → plate inside 2 s) must end on the latest page's music: no stacked fades, no stuck silence. Test in Task 4 (`Transitioner`).
3. **Replay drawing pressed repeatedly** restarts the build-up, and part gains never exceed 0.35. Test in Task 4.
4. **Paused, navigate, then play** plays the current page's target as a full loop, with no build-up. Test in Task 4.
5. **Engine chunk fails to load** (offline, or a tab open across a deploy): Radio shows "Couldn't load the station, Reload" and the site keeps working. Test in Task 5.

**Files:**

**Interfaces:**

- Produces:
  ```ts
  // station-transition.ts: a pure clock-driven level controller, no Strudel
  export type Target =
    | { kind: 'dish'; pattern: StationPattern; take: number; draws: boolean }
    | { kind: 'ambient'; pattern: StationPattern }
  export interface Levels { master: number; parts: number[] }   // parts.length 5
  export class Transitioner {
    constructor(opts: { evaluate: (code: string) => void; now: () => number })
    /** Called on every target change; playing=false only records it. */
    set(target: Target, playing: boolean): void
    play(): void; pause(): void
    /** Current levels at now(); also fires evaluate() when a fade-out completes. */
    levels(): Levels
  }
  // station-engine.ts: the only Strudel importer, dynamically imported
  export async function startEngine(t: Transitioner): Promise<void> // initStrudel + audio resume; registers globalThis.layer
  export function stopEngine(): void // hush()
  ```
- `layer(i)` = `ref(() => { const l = t.levels(); return l.master * l.parts[i] })`. The engine also wraps every evaluated pattern with `.postgain(ref(() => t.levels().master))` for tracks without `layer()`. *Builder's call* on the exact `ref`/`postgain` usage, as long as gain follows `levels()`.
